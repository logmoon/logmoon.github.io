    • Project Description

    I recently started going to the gym, and I found myself always forgetting what exercices I did, and how much weight/sets/reps I did for each. I swear, I have this constant memory leak in my brain, and whenever it gets potent in a certain area, I usually just build an app to help me.

    On the other hand, I've also always wanted to try out react native, I've tried flutter before and it was fun, but I didn't want to use it again, just for the sake of learning a new tool. So I decided to kill two birds with one stone, and build an app that will help plug the constant memory leak in my brain, and learn React Native!

    What I ended up with is a really simple workout tracker, where I can create workouts, and exercices within those workouts, I can log the sets, weights and reps within the exercice and even attach an image or take a picture of the exercice just in case it's a machine that I might forget.
